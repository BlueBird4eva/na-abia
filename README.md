# Naabia
**Navigate All 17 LGAs in Abia State**

Naabia is a fast, offline-first Progressive Web App that helps people find places, services, and directions across all 17 LGAs in Abia State, Nigeria.

### ✨ Features
- **Works Offline**: Full app works without internet after first visit
- **All 17 LGAs**: Aba North, Aba South, Arochukwu, Bende, Ikwuano, Isiala Ngwa North, Isiala Ngwa South, Isuikwuato, Obi Ngwa, Ohafia, Osisioma, Ugwunagbo, Ukwa East, Ukwa West, Umuahia North, Umuahia South, Umu Nneochi
- **Installable**: Add to Home Screen on Android & iOS
- **Responsive**: Works on mobile, tablet, and desktop
- **Fast**: Cached assets for instant loading

### 🚀 Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Service Worker for offline caching
- Web App Manifest for installability

### 📲 Install Naabia
1. Visit https://naabiapro.netlify.app
2. Tap `Install App` or `Add to Home Screen`
3. Use Naabia offline anytime
